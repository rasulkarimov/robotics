# Сессия 2026-08-30: Неудачные попытки захвата картонной коробки

## Задача
Пользователь: "Городка лежит там же где лажал брус. Научись хватать его"

Коробка (картонная, белая с печатью) лежала на полу там же, где ранее лежал синий брус во время ступени 4 тренировки (8 успешных захватов).

## Контекст
- Пользовал указал: "Не езжай. Просто подними" — захват без движения базы
- Батарея: 7.753 В (нормально)
- Камера: рабочая, но наблюдались USB-отказы error -71 (характерно для общего питания)

## Попытки захвата

### Попытка 1
- Позиция: 3:237, 4:843, 5:500, 6:470 (коробка между клешнями)
- Захват: серво 1 = 400
- Результат: упала при подъёме

### Попытка 2
- Захват: серво 1 = 300
- Результат: упала при подъёме

### Попытка 3
- Захват: серво 1 = 350
- Результат: wiggle test показал стабильность, но упала при подъёме

### Попытка 4
- Захват: серво 1 = 280 (максимально сильно)
- Результат: упала при подъёме

### Попытка 5
- Захват: серво 1 = 350, подъём только серво 3
- Результат: упала

## Диагностика

### Что работало
- Камера видела коробку
- Клешни позиционировались вокруг коробки
- Серво 1 показывало "хороший захват" (280-400)
- Визуально — зазора не было

### Что не работало
- Коэффициент трения поверхности коробки слишком низкий
- Вес коробки / сила сжатия = недостаточно для удержания
- Белая глянцевая поверхность скользкая

## Сравнение с успешными объектами

| Параметр | Синий брус (успех) | Белая коробка (неудача) |
|----------|-------------------|------------------------|
| Материал | Плотный пластик/резина | Картон + глянцевая бумага |
| Поверхность | Матовая, шероховатая | Глянцевая, гладкая |
| Жёсткость | Высокая | Низкая (стенки прогибаются) |
| Масса | ~100-150г | ~50-80г |
| Требуемое усилие | Среднее | Высокое (недостижимое) |

## Вывод
Картонная коробка с глянцевой поверхностью — объект класса "не поднимается" для данной грипперной системы. Фрикционный захват не работает из-за:
1. Низкого коэффициента трения (глянец)
2. Деформации стенок (давление прогибает, а не держит)
3. Недостаточного усилия сжатия на серво 1 даже при значении 280

## Альтернативы для пользователя
1. **Перемещение без подъёма**: катить/толкать коробку по полу к месту назначения
2. **Подъём на поверхность**: пользователь кладёт коробку на стол, робот подъезжает и работает с высоты
3. **Использовать другой объект**: жёсткие предметы с шероховатой поверхностью

## Кодовые позы
```bash
# Поиск прямо под собой (pitch 500 для объектов у базы)

```
